##  About The Project

**AgriFlora – Precision Farming Rice Market Hub** is a web-based smart agriculture platform designed to support farmers and agricultural stakeholders through digital technology.

The platform integrates agricultural information, rice variety management, rice market information, rice price forecasting, an AI-powered farm assistant, and agricultural learning resources into one centralized system.

AgriFlora aims to make agricultural information more accessible, improve awareness of rice market trends, and help users gain valuable knowledge about rice cultivation and agricultural practices.

This project was collaboratively developed by a team of five students as an academic group project to explore the practical application of modern web technologies and digital solutions in the agricultural sector.

##  Project Objectives

- Promote digital transformation in the agricultural sector.
- Provide accessible information about rice varieties and cultivation.

## ⚙️ Installation & Setup

Follow these instructions to run AgriFlora on your local machine.

### Prerequisites

Make sure you have installed the following:

- Python 3.x
- Git
- Visual Studio Code (Recommended)
- A modern web browser

### Step 1: Clone the Repository

```bash
git clone https://github.com/khaingmar123098-hue/AgriFlora-Precision-Farming-Rice-Market-Hub.git
```

### Step 2: Navigate to the Project Directory

```bash
cd AgriFlora-Precision-Farming-Rice-Market-Hub
```

### Step 3: Create a Virtual Environment

```bash
python -m venv venv
```

### Step 4: Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### Step 5: Install Required Dependencies

If a `requirements.txt` file is available, run:

```bash
pip install -r requirements.txt
```

Otherwise, install the dependencies required by the backend source code.

### Step 6: Run the Application

```bash
python backend/app.py
```

Check the application configuration for the correct local server address and port.
